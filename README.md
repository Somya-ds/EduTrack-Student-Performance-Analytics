# EduTrack – Student Performance & Analytics System

EduTrack is a Python-based Student Performance and Analytics System designed to manage student information, analyze academic performance, and present results through data visualizations.

The project demonstrates the practical use of Python programming concepts, Object-Oriented Programming (OOP), NumPy, and Matplotlib to develop a simple academic data analysis system.

---

## 📌 Project Overview

EduTrack stores and manages student information such as student ID, name, age, semester, email, marks, and attendance.

The system automatically calculates:

- Total marks
- Percentage
- Grade
- Pass/Fail status
- Attendance eligibility
- Class average
- Subject-wise averages
- Highest performer
- Lowest performer
- Average attendance
- Grade distribution
- Pass/Fail distribution
- Marks statistics

The project also uses graphical visualizations to make student performance easier to understand.

---

## 🎯 Objectives

The main objectives of EduTrack are:

- To develop a Python-based student management system.
- To implement Object-Oriented Programming concepts.
- To manage student marks and attendance.
- To calculate academic performance automatically.
- To analyze student performance using NumPy.
- To identify the highest and lowest performing students.
- To calculate subject-wise and class-wise averages.
- To visualize academic data using Matplotlib.
- To demonstrate the practical application of Python in data analysis.

## ✨ Features

### 👨‍🎓 Student Management
- Store student details
- Display student records
- Search students using Student ID
- Delete student records

### 📊 Performance Analysis
- Calculate total marks
- Calculate percentage
- Assign grades
- Determine Pass/Fail status
- Calculate class average
- Calculate subject-wise averages
- Find highest and lowest performers

### 📝 Attendance Analysis
- Store attendance percentage
- Calculate average attendance
- Determine attendance eligibility

### 📈 Data Visualization

EduTrack uses Matplotlib to generate:

1. **Bar Chart** – Average marks by subject
2. **Pie Chart** – Pass/Fail distribution
3. **Line Chart** – Student performance
4. **Histogram** – Distribution of student percentages
